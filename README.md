# Calcite Cursors

Calcite Cursors are a set of cursors created by me (Lad_Flaver) for Linux. The most unique feature is that the loading wheel animation is a part of the pointer itself. The name "Calcite" comes from the fact that I'm a huge geology nerd and thought it sounded cool.

# To use

Download a release and put it in your /usr/share/icons folder and select it through whatever means your distro provides for that.

# To make your own version

Modify the SVG files of your choosing, export as PNGs, and use xcursorgen to create the new cursors. More information can be found in the Additional-Info.txt file.
